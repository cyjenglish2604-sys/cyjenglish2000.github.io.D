내신분석 원장용 사용 안내

내신분석은 학교 시험을 본 뒤 학교 기출분석과 학생 개인 성적을 심층 분석해 주는 앱입니다. 학교 기출분석 엑셀을 등록하고 리포트를 생성하는 방법을 안내합니다.

리포트를 생성할 때마다 비용이 발생합니다

AI가 리포트를 생성하기 때문에 생성할 때마다 토큰(비용)이 발생하며, 건당 비용은 학원 부담입니다. 한 번에 정확한 리포트가 나오도록 기출분석 엑셀 작업에 공을 들여 주시기 바랍니다.

아카데미 로그인

edutest.kr/academy 로 접속해 아카데미_캠퍼스 아이디와 비밀번호로 로그인합니다. 캠퍼스 에듀시스 아이디·비밀번호와 동일합니다.

2

내신분석 메뉴 누르기

edusys 홈 화면 아이콘 중 내신분석을 누릅니다. 위쪽에 기출분석 등록, 생성, 배정, 통계 탭이 있습니다.

3

샘플 파일 받아서 작성

기출분석 등록 탭에서 년도, 구분, 시험구분, 학년, 학교를 고르고 검색한 뒤, 업로드 샘플 파일을 내려받아 작성합니다.

샘플 파일의 모든 항목을 입력해 주시기 바랍니다

반드시 지정된 샘플 파일로 작성하고 모든 항목을 입력한 뒤 업로드해야 분석 통계가 정상적으로 나옵니다. 저장할 때 확장자를 xls로 지정해야 정상적으로 등록됩니다. 문제 유형과 세부 내용은 기출 경향에 맞춰 임의로 작성하시면 됩니다.

4

파일 선택 후 등록

파일 선택으로 작성한 엑셀을 고르고 등록을 누릅니다.

5

기출분석 리포트 생성

표 아래 버튼 3개 중 기출분석 리포트 생성을 누릅니다. 세 버튼은 기출분석 등록 화면과 생성 화면 어디에서나 쓸 수 있습니다.

6

배정 확인

배정 탭에서 생성된 시험과 학교를 확인합니다. 자동으로 배정되기 때문에 별도의 배정은 필요하지 않습니다.

엑셀 작성 Q&A

기출분석 엑셀을 작성할 때 자주 하는 질문입니다.

1논서술형 한 문제가 1-1, 1-2로 출제되었습니다

각각 넣으면 총 문항수에 오류가 생깁니다. 번호 항목에 동일 번호를 입력한 뒤 논서술형 1-1, 논서술형 1-2로 기입하면 하나의 문항으로 인식합니다.

예시엑셀번호 23, 논서술형 1-1 / 엑셀번호 23, 논서술형 1-2

2출처는 교과서인데 교과서 변형문제가 출제되었습니다

출처는 교과서로 하고, 문항별 세부사항에 교과서 변형으로 기입합니다.

세부사항은 자세히, 다만 너무 장황하지 않게

문항별 세부사항에 기입한 내용을 그대로 반영하기 때문에 자세할수록 좋습니다. 특이 사항도 세부사항에 기입하면 공통 카테고리로 잡혀 통계가 한눈에 들어옵니다.

생성

등록된 기출분석으로 리포트 생성

년도, 구분, 시험구분, 학년, 학교를 고르고 검색합니다. 엑셀이 등록된 시험은 기출분석 등록 칸에 Yes로 나옵니다. 화면 아래에 기출분석 등록 화면과 같은 버튼 3개가 있습니다.

배정

학교 목록, OMR과 리포트 확인·수정·다운로드
다시 생성할 때마다 토큰(학원 비용)을 사용합니다

신중하게, 꼭 필요한 경우에만 사용해 주시기 바랍니다.

통계

학년별·담임별 학생 내신성적 조회

년도, 구분, 시험구분, 학년, 담임을 고르고 조회합니다. 학생별 점수, 등급, 반평균, 학년평균이 나오고, 옆에 엑셀 버튼이 있습니다.

성적기준은 학생들의 가채점 기준입니다. 내신등급은 지필점수를 5등급제로 나타낸 것입니다.

자주 묻는 질문

리포트 생성에 비용이 듭니까?

네. AI가 리포트를 생성하기 때문에 생성할 때마다 토큰(비용)이 발생하며, 건당 비용은 학원 부담입니다.

생성한 리포트를 다시 만들 수 있습니까?

네. 배정 탭에서 리포트를 삭제한 뒤 기출분석 리포트 생성을 누르면 됩니다. 다시 생성할 때마다 비용이 발생하니 꼭 필요한 경우에만 사용해 주시기 바랍니다.

별도로 배정해야 합니까?

아닙니다. 자동으로 배정되기 때문에 별도의 배정은 필요하지 않습니다.

AI가 만든 리포트 내용을 고칠 수 있습니까?

네. 리포트를 열어 수정을 누르고 내용을 고친 뒤 저장하면 됩니다.
